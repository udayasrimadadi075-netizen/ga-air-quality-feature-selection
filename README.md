# Genetic Algorithm-Based Feature Selection for Air Quality Forecasting

This project applies a Genetic Algorithm to select important features for air quality prediction. The goal is to identify the most relevant environmental and pollutant-related variables and use them to build efficient machine learning models.

## Features

- Data preprocessing and analysis
- Genetic Algorithm-based feature selection
- Selection of important environmental and pollutant features
- Machine learning model training
- Model performance evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
